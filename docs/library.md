# 个人知识库基础版

更新于 2026-11-05。跨资料全文匹配、标签筛选和命中定位已开发，测试与验收按用户安排后置。模型 Key 由用户最后在本机填写。

## 搜索与筛选

「资料」页面支持检索已保存的标题、整理摘要和已提取原文。输入多个词时用空格分隔，最多 8 个词、共 200 字，每个词都需要在同一份资料的可检索内容中出现。标题和摘要中的整段匹配优先展示，其余结果按保存时间排序。

支持以下筛选。

- 资料类型包括消息、粘贴文档、会议文字稿、PDF、录音和网页。
- 整理状态包括待整理、处理中、已整理和需要处理。
- 标签按用户保存的分类过滤。
- 版本范围默认当前版本，可切换历史版本或全部版本。
- 保存日期采用上海时区，筛选资料保存时间。

当前使用 SQL 文本匹配。每页默认 20 份，最多 50 份，分页 offset 上限 10000，到达边界后页面提示缩小筛选范围。查询覆盖符合条件的全部用户资料，结果按页返回。

PDF 扫描页和录音需要先完成 OCR 或转写，正文才能进入检索。尚未提取的资料仍可通过标题查找。部分解析结果保留覆盖状态。

## 标签

每份资料最多 20 个标签，每个标签 1 至 30 字。编辑时用逗号分隔，空白表示清除标签。标签采用 Unicode NFKC 规范化，大小写等规范化后相同的名称视为同一标签。

文件标签绑定资料根记录，修订后的各版本共用同一组标签。保存带标签版本号，旧页面修改返回冲突并要求刷新。全文搜索结果和资料详情均可编辑标签。

标签目录最多列出 500 项并标记截断状态，卡片上的标签也可以直接点击筛选。

## 命中定位

结果显示原文摘录与检索词高亮。点击命中位置后，普通文本按字符位置突出显示，PDF 回到对应页与片段，录音定位到对应转写片段的时间点。摘要和标题命中使用各自的标识。

原文位置使用 Unicode code point 计数，前端按相同字符单位转换。引用保留具体来源版本和片段 ID，历史版本从其原始内容回查。播放受浏览器音频策略影响，音频控件可用于手动播放。

筛选条件在同一网页会话中返回资料列表时保留，切换账号时重置。删除文件资料时，其标签与元数据一起清理，所有删除版本从检索结果中排除。

## 向量检索接入准备

当前交付资料分块清单和向量模型配置状态接口。

分块接口按来源版本生成稳定 ID，返回来源内容摘要哈希、原文、片段 ID、字符位置和原有定位信息。每块最多 2000 个字符，相邻块在同一来源片段内重叠 200 字，末块覆盖剩余内容。分块分页默认 50 项，最多 100 项。

模型配置沿用现有网关注册表，使用独立的 `knowledge_embed` 任务。该任务需要显式映射到已声明的 embedding 模型。状态接口返回所选模型及凭据配置状态，`index_ready` 当前为 `false`。

资料向量索引构建、远端 embedding 调用和语义查询仍待接入。填写现有文字模型 Key 后，全文匹配继续使用当前规则。后续向量管道需在写入索引前核对来源版本与内容摘要哈希，并沿用资料用户范围及删除规则。

## 维护位置

实现位于 `app/library/`、`app/data_access/library.py` 和 `static/js/library.js`。两个新增私有表为 `library_metadata` 与 `library_tags`，已注册到现有 DAL 及 owner RLS migration。原始来源、资料版本和片段复用现有数据模型。

API 前缀为 `/api/arrangements/library`。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/search` | 全文匹配、筛选及分页 |
| GET | `/tags` | 用户标签目录与资料数 |
| GET | `/sources/{id}/metadata` | 根资料标签和版本信息 |
| PUT | `/sources/{id}/tags` | 带版本号确认保存标签 |
| GET | `/sources/{id}/chunks` | 向量管道所需的分块清单 |
| GET | `/vector-status` | 向量模型配置与接入状态 |

本轮检查范围为代码审阅、静态语法和应用启动。功能测试、浏览器定位验收、Postgres 实测和真实模型联调均保留待执行状态。
