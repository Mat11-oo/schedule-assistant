# 本机启动、配置与开始指南

更新于 2026-11-05，适用于 macOS 本机运行。

## 启动与停止

在项目根目录双击 `启动Personal-Agent.command`。启动器会读取本机配置，启动或复用当前项目服务，并使用 Chrome 打开应用。终端显示运行地址和日志位置，按回车可关闭启动窗口，后台服务继续运行。

双击 `停止Personal-Agent.command` 关闭服务。程序会核对监听进程的系统用户、工作目录、启动命令及启动时间，再发送正常退出信号。端口由其他项目占用时，启动器显示核对提示。

运行地址为 `http://127.0.0.1:8787`。启动入口默认打开首页，第一次生成本机配置时打开设置与开始指南。

终端入口同样可用。

```bash
.venv/bin/python scripts/local_app.py start
.venv/bin/python scripts/local_app.py stop
.venv/bin/python scripts/local_app.py status
```

自动化启动或只需终端地址时，使用 `start --no-open`。Finder 入口添加 `--pause`，完成后等待回车。

运行元数据保存在 `data/launcher/state.json`，日志保存在 `data/launcher/server.log`。该目录权限为 `700`，状态、锁文件及日志使用本机私有文件权限。启动锁用于串行化重复点击，PID 记录在使用前重新核对系统信息。

## 本机环境

本项目当前已经准备 `.venv` 与依赖。在新机器上，需要先安装 Python 3.12 并按项目依赖准备环境。

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt -c requirements.lock
```

首次启动缺少 `.env` 时，启动器会生成随机登录签名密钥、本机数据目录、站内提醒配置和空服务密钥的百炼预设。已有 `.env` 继续用于启动。操作系统环境变量按原应用的优先级覆盖 `.env`。

数据与附件的位置以设置页显示的实际保存目录为准。启动器的运行记录固定保存在项目 `data/launcher` 目录。

## 设置与开始指南

点击左侧导航底部「设置」，或打开 `http://127.0.0.1:8787/#setup`。

设置页集中显示以下信息。

- 文字理解、扫描页识别和录音转写的模型与配置状态。
- 向量模型选择和当前接入准备状态。
- 站内提醒调度器与资料后台处理的运行状态。
- 当前用户的工作时段、每日简报设置和下一次简报记录时间。
- 数据存储方式与实际目录。

页面使用当前服务进程配置，密钥填写完成后需要重启应用，再刷新状态。云服务响应和识别质量在后续联调中核对。

开始指南读取真实的保存记录，展示是否已保存过来源、任务、工作时段与排期。各步骤可直接进入已有页面或设置对话框。

1. 收集一条消息或已有文字，保存后从原文手动添加事项。
2. 从待处理核对归属、日期和工作量，确认创建或关联任务。
3. 保存工作时段与每天容量，再登记已有固定安排。
4. 生成排期预览，核对后保存到今日时间线。
5. 查看每日简报，按需设置每日站内推送。

今日的开始提示可以选择「已了解」，该选择按浏览器账号范围保存。设置与开始指南可随时再次打开。

## 最后填写服务 Key

在项目目录运行现有的隐藏输入配置入口。

```bash
.venv/bin/python scripts/configure_bailian.py
```

打开「设置 → 模型与 API Key」，分别配置文字理解、复杂任务、扫描件识别和录音转写。服务商预设、模型名称、地址和密钥均可在应用内选择或填写。密钥留空保留已有配置，更换地址需要对应的新密钥。未使用的服务可将模型和地址均留空。

配置保存到本机 `.env`，文件权限为 600，保存后对后续请求生效。此设置影响本机应用的所有会话，仅允许本机访问。保存只检查格式，实际可用性需联调验证。已有高级模型路由时，在本机配置文件中继续管理。终端配置入口仍可使用，终端修改后需重启服务。向量模型和语义索引仍按知识库说明单独接入。

## 数据保存与恢复

关闭网页后，服务进程可继续执行已配置的后台任务。停止服务后，提醒与资料处理随进程暂停，持久化任务记录保存在数据目录。

备份时先确认服务已停止，再保存设置页显示的数据目录与项目 `.env`。恢复时保留原登录签名密钥，并使用同一浏览器会话继续访问原账号数据。目录中可能有多个本机账号的数据，备份文件需存放在个人可控位置。

## 当前交付状态

启动器检查本机进程归属和 HTTP 就绪状态，设置页读取当前配置与用户保存记录。这些检查用于加载应用和显示状态。业务功能测试、浏览器交互验收及真实云服务联调，按用户安排继续后置。


## 文档工作空间

首页、任务和空间设置以提供的 Craft 手机界面截图为布局依据。移动端底部的首页、任务、日历按钮用于切换页面，右侧彩色圆环打开小助，加号提供新建文档与导入入口。

文件夹、文档位置和收藏保存在当前用户的本机服务数据库。文件夹可新建、改名、调整上级或移除，移除后文档回到未分类。桌面端也可将文档拖到左侧文件夹。快捷搜索使用 `⌘ K`／`Ctrl K`，支持键盘选择结果。

桌面端文档标签页保存在当前设备的浏览器内。右侧面板提供目录、信息和助手。导入资料的助手沿用已有原文问答与云处理许可，输入期间后台刷新会保留编辑状态。

共享服务和外部文档发布尚未接入，相关界面会说明接入状态。独立 macOS 桌面应用封装仍待交付。

使用 PostgreSQL 的环境需要按现有 owner 迁移流程更新结构与行级访问策略，新增的 `library_workspaces` 已纳入私有表注册。本机 SQLite 在正常启动时准备新表。
